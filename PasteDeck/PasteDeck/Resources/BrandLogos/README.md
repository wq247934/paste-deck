These local SVGs are used only to identify translation providers and model services in PasteDeck.

- Baidu, Tencent Cloud, Alibaba Cloud, DeepSeek, Zhipu, Xiaomi MiMo, OpenAI, MiniMax, and Qwen: [Lobe Icons](https://github.com/lobehub/lobe-icons) (MIT), whose icon pages link back to each official service.

- Youdao: [Youdao vector mark](https://freebiesupply.com/logos/youdao-logo/), cross-checked against the wordmark shown on Youdao's official services.
